🔐 Teacher Login

พื้นที่เข้าสู่ระบบสำหรับครู สำหรับเปิดระบบตรวจคะแนนและรอยทดทดลอง

หน้านี้ยังไม่ได้ตั้งค่าเชื่อมต่อ Supabase กรุณาเพิ่ม Project URL และ Publishable key ในไฟล์ก่อนใช้งาน

เปิดอีเมลบนอุปกรณ์เดียวกัน แล้วกด Magic Link เพื่อกลับมาที่หน้านี้ ลิงก์ใช้ได้ครั้งเดียวและมีเวลาหมดอายุ

✓ เข้าสู่ระบบ Supabase Auth แล้ว

เข้าสู่ระบบแล้ว กดตรวจสอบสิทธิ์ครูก่อนเปิดหน้าตรวจผลงานทดลอง (ยังต้องใช้รหัส Pilot แยก)

👩‍🎓 รายชื่อนักเรียนจาก Classroom

อ่านรายชื่อเฉพาะห้องเรียนที่บัญชีครูได้รับอนุญาต ผ่าน Teacher Review API • ไม่แก้ไขข้อมูลต้นฉบับ

ผลงานนักเรียน

อ่านรอยทดจากโปรเจกต์ Classroom จริงผ่านสิทธิ์ครู • ยังไม่ใช่ประวัติคะแนนทั้งหมด (คะแนน Pilot อยู่คนละโปรเจกต์)

📊 ประวัติคะแนนทุกครั้งที่เล่น

ข้อมูลจาก Classroom จริง • แสดงสูงสุด 100 รอบล่าสุดต่อครั้ง • รวมรอบที่ไม่ผ่านและการเล่นซ้ำ

✍️ รอยทดที่ส่งเข้าระบบ

ประวัติคะแนนในหน้าด้านล่างยังเป็น Pilot แยกต่างหาก ไม่ได้รวมกับข้อมูลจริงโดยอัตโนมัติ

📊 ตรวจผลงานนักเรียน — Pilot

ข้อมูลนี้อยู่ในระบบทดลองอีกโปรเจกต์หนึ่ง ต้องกรอกรหัสครู Pilot ภายในหน้าด้านล่างอีกครั้ง จนกว่าจะเชื่อมสิทธิ์ฝั่งเซิร์ฟเวอร์เสร็จ ไม่ใช่ระบบโรงเรียนจริง
